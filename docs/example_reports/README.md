# Example reports

These are sample outputs from running the eval harness in **replay mode** (no bio tools installed). They are checked in so reviewers can see what the harness emits without standing up the full toolchain.

## `replay_run_report.md`

Generated by:

```bash
hyphae init out/ examples/junttila2021_intent.yaml   # synthetic local FASTQs
hyphae run --workdir out/ --replay manifest.json --deterministic
hyphae bench --workdir out/ --out out/report.md
```

The replay manifest only records assemblies, so:

- `total_samples_assembled` passes — the agent graph reaches assembly for all six samples.
- BUSCO, BGC, T1PKS checks fail with `—` because no BUSCO / antiSMASH numbers exist yet.

This is the **shape** of a real benchmark run. When the toolchain (or hosted antiSMASH) is wired in, the same report will fill in the per-sample numbers and turn `FAIL` into `PASS` (or surface a real, defensible gap).
